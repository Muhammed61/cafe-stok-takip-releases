# Kafe Stok Takip — Sürümler

Kafe Stok Takip masaüstü uygulamasının Windows kurulum dosyaları burada yayınlanır.

- **İlk kurulum:** [Releases](https://github.com/Muhammed61/cafe-stok-takip-releases/releases/latest) sayfasından `KafeStokTakip-Setup-x.y.z.exe` dosyasını indirip çalıştırın.
- **Güncellemeler:** Kurulu uygulama yeni sürümleri buradan kendiliğinden indirir ve kurar.

Bu repoda kaynak kod bulunmaz.
